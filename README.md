## 🏆 How I work

- 🔐 A role that can **view** attendance is not a role that can **close** it. The API still rejects the call.
- 📡 Three clients on one API means a breaking field is a mobile incident. Version the contract.
- 💳 PayOs and VNPAY callbacks are the checkout. The SPA does not mark paid because the browser felt lucky.
- 🧭 Team Leader meant owning the contracts, not writing every line.
- 🤖 Gemini is a chat box or a last-step reviewer. It is not the architecture.
